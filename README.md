# AI/ML Odyssey

A self-study roadmap for AI and machine learning, curated by **signal-to-time ratio** instead of completionism. Track your progress through courses, books, and platforms — all saved locally in your browser.

🔗 **[Live Demo](https://lakshay-lg.github.io/ai-ml-roadmap/)**

---

## Features

- **📍 Visual learning path** — A recommended 5-step sequence through priority courses (Orient → See → Speak → Build → Act)
- **📅 Weekly planner** — Drag courses onto days to plan your study week
- **✅ Progress tracking** — Mark courses as started/completed, check off individual lectures
- **🎨 Light & dark mode** — Toggle between warm cream and rich dark themes
- **🎛️ Tweaks panel** — Customize accent color, density, layout, and visibility of planner/path
- **💾 Local storage** — All progress persists in your browser; no login required

## Usage

1. **Open `index.html`** in any modern browser (Chrome, Firefox, Safari, Edge)
2. Click a course to mark it as **Started** or **Completed**
3. Expand lectures and check them off individually
4. Drag courses to the weekly planner to schedule your study time
5. Click the **🌙 / ☀️ toggle** in the top-right to switch themes
6. Use the **Tweaks** button (bottom-right corner) to customize appearance

All progress is saved in `localStorage` — it persists across sessions and works offline.

---

## Deployment (GitHub Pages)

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set **Source** to `main` branch, `/root` folder
4. Your site will be live at `https://lakshay-lg.github.io/ai-ml-roadmap/`
